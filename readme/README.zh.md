# 漫画

hoardodile 内容插件：按章阅读的漫画阅读器，支持滚动/翻页两种模式、页内留言与阅读进度恢复。

## 功能

- 章节目录：页面文件夹（子目录即章节）与单文件漫画压缩包 —— CBZ/zip、CBR/rar、CB7/7z、CBT/tar、EPUB —— 页面在首次预览时通过主机的 `extractArchive` 物化（非 zip 格式需要随附的 7-Zip 二进制）。
- 滚动与翻页视图、缩放；首帧预览；分章进度与阅读位置恢复。
- 页内留言锚定当前页。
- 可在内容库搜索过滤器中按内容（图片 / 动图）筛选资源；页面参与重复检测的哈希计算。

## 要求

- hoardodile ≥ 0.1.6（详见仓库 README）。
- 安装前请确认信任该仓库——插件代码在受限沙箱中作为服务端代码运行。
