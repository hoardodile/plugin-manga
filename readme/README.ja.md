# 漫画

hoardodile のコンテンツプラグインです。章ごとに読む漫画リーダーで、スクロール/ページ送りモード、ページごとのメッセージ、読書位置の復元をホストアプリのビューアで提供します。

## 機能

- 章のディレクトリ：ページフォルダー（サブディレクトリが章）と、単一ファイルの漫画アーカイブ（CBZ/zip、CBR/rar、CB7/7z、CBT/tar、EPUB）に対応。ページは初回プレビュー時にホストの `extractArchive` で実体化されます（zip 以外は同梱の 7-Zip が必要）。
- スクロール/ページ送りビュー、ズーム、各章の進捗と読書位置の復元。
- 現在のページに紐づくページごとのメッセージ。
- ライブラリの検索フィルターで内容（画像 / アニメーション）ごとに絞り込めます。ページは重複検出のハッシュ算出に使われます。

## 要件

- hoardodile ≥ 0.1.8（詳しくはリポジトリの README を参照）。
- インストール前にリポジトリを信頼してください。プラグインコードは制限付きサンドボックス内でサーバー側として実行されます。
